# maxandtaylor2027.com

Taylor & Max's wedding website — May 29, 2027, The Willows, Villanova PA.

Static site, no build step. Edit the files, push to `main`, GitHub Pages serves it.

- `index.html` — save-the-date front door: names, date, mailing-address form (posts to FormSubmit → maxshinreceipts@gmail.com, redirects to `/thanks/`)
- `details/index.html` — the full wedding website (story, venue, travel, photos)
- `thanks/index.html` — post-submit thank-you page
- `css/styles.css` — palette + styling (colors from Taylor's inspiration board)
- `js/main.js` — countdown, scroll reveals, photo lightbox
- `img/` — web-sized engagement photos (EXIF-stripped; originals NOT in this repo)
- `fonts/` — self-hosted Cormorant Garamond + EB Garamond (woff2)
- `wedding.ics` — "Add to calendar" file (all-day May 29, 2027)
- `CNAME` — custom domain for GitHub Pages

Photography: Chloe Dawson Photography (engagement session).

Planned later: RSVP form (when invitations go out, ~March 2027), registry links, hotel room-block details (once contracts are countersigned).
